# Security policy

Skills run with the permissions of the coding agent that loads them, so a skill is executable
trust. Report suspected vulnerabilities, malicious content or unsafe scripts privately.

- Use GitHub private vulnerability reporting on this repository (Security tab), or
- use the TI product security contact (TODO(legal): add the confirmed PSIRT address or URL before the first public release).

Do not open a public issue for a vulnerability. We acknowledge reports and agree a fix and
disclosure timeline with the reporter.

See [docs/trust-and-safety.md](docs/trust-and-safety.md) for the rules every skill must follow.
